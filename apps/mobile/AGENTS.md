# 单 APK 共同规则

继承仓库根 AGENTS.md。此目录只允许建立一个移动应用、一个公共入口和一套安卓打包配置。当前尚无业务代码或 APK。

学生模块 src/modules/student 归魈嘶，档口模块 src/modules/merchant 归漪x3，管理模块 src/modules/admin、src/app、src/shared、根配置、依赖和将来的 android/ 归 spcuteag。模块 Agent 必须继续读取本模块 AGENTS.md，不改队友代码或公共依赖。

公共层负责登录、服务端授权后的角色入口、路由、网络请求、位置权限和定位方法。账号没有的角色不能通过页面切换获得；后台对订单和管理操作再次检查权限。学生模块获取范围判断，不直接持久化或上传原始坐标。

通过网页技术加 Capacitor 构建，具体框架与版本由 spcuteag 统一。不要三人各建一个项目，不引入与公共选择冲突的工具。网页仅作开发辅助，最终使用 APK 验收。后端运行在独立服务环境，真机不能把电脑 localhost 当作共同地址。

第 1 天先完成最小 APK 安装、连接测试服务及一次定位授权/拒绝；第 2—3 天完成同一 APK 的下单到核销；第 4—5 天完成异常、权限和跨角色检查并交安装包。每次记录 APK 版本、服务版本及真实测试设备；不能用样例或浏览器检查冒充安卓真机结果。

android/ 由工具生成，签名文件、密码、.env 和真实数据不入库或 team-context。应用资源/生成文件的提交范围由 spcuteag 根据真实工具说明确定，不把 APK 构建输出当源代码。
