# 吉祥点餐前端独立工程 (frontend/)

## 1 项目背景与目标

本项目是吉祥点餐前端工作副本，基于 React 19 + TypeScript + Vite 8 构建，对齐视觉参考设计稿（`frontend/photo/`），在保障与主应用架构（`apps/mobile`）契约兼容的前提下，实现学生端全链路高保真视觉与交互体验还原。

## 2 核心模块边界

- **页面范围**：
  1. 首页与选店（已完成拍立得轮播与三店铺展示）
  2. 菜单与加购
  3. **预约取餐与时段用餐方式页（SlotDiningPage - 页面一）**
  4. **确认订单页（ConfirmPage - 页面二）**
  5. 订单详情与取餐码页
  6. 订单历史列表页
- **文件权限与硬边界**：
  - 严格限制在 `frontend/` 目录内，不侵入根目录或外部模块。
  - 数据源严格支持 `sample`（样例演示）与 `real`（真实接口）双模式切换。
