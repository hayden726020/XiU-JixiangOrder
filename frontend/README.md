# 前端交接副本

本目录是供下一位前端架构师 Agent 使用的 React + TypeScript + Vite 源码副本，来源于当前 `apps/mobile/`。它保留了原应用，作为独立工作副本供前端继续设计和实现。

## 当前完成内容

- 学生端首页：校园头图、拍立得店铺轮播、样例推荐菜、底部导航。
- 三张店铺图自动轮换，支持触屏左右滑动、左右按钮和圆点切换。
- 店铺数据继续使用原学生模块数据源；真实服务返回超过三家时，其他店铺可从展开列表进入。样例模式只有两家店，第三张明确标记为图片展示，不会伪装成可点餐店铺。
- 学生菜单、时段、用餐方式、下单确认、订单列表与详情。
- 商家和管理端现有页面及共享前端入口。
- 校园、档口和餐食图片资源位于 `src/modules/student/assets/`。

## 运行

使用 Node.js 22.12 或更高版本，在本目录执行：

```powershell
npm install
npm run dev
```

打开 Vite 显示的本地地址，再进入 `#/student` 查看学生端首页。

检查命令：

```powershell
npm run typecheck
npm run build
```

真实服务模式和样例模式按代码现有配置切换。页面上的样例数据不代表真实店铺、菜单、供应或订单。

## 与主应用的关系

正式单 APK 仍由 `apps/mobile/` 维护。此目录是便于新前端 Agent 在限定范围内工作的副本；修改后需检查与主应用及队友提交的差异，再由主应用负责人决定如何同步。不要把此副本的独立启动或构建结果描述成 APK 真机验收。
